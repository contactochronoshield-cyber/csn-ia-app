# Chrono Lab

Laboratorio educativo integrado en CSN IA.

## Sistemas

- Linux
- Windows / PowerShell
- FreeBSD
- Android / Termux
- Cisco IOS Lab
- ChronoOS

## Áreas

- Sistemas operativos
- Networking
- Ciberseguridad defensiva
- Telecomunicaciones
- 4G / LTE
- 5G
- LoRa / LoRaWAN
- Edge Computing
- ChronoNet
- ChronoOS
- Sentinel IA
- GIS
- Telemetría

## Seguridad

Los comandos del laboratorio son simulados y no ejecutan operaciones
peligrosas ni modifican el dispositivo del usuario.

Chrono Lab debe evolucionar hacia escenarios con estado, evidencia,
diagnóstico y evaluación.
